# Pruebas

## Sistema de Préstamo de Equipos Tecnológicos

Esta carpeta contiene las evidencias de las pruebas realizadas al sistema durante el Sprint.

Las pruebas permiten verificar que las funcionalidades desarrolladas cumplan con los criterios de aceptación establecidos.

## Pruebas consideradas

Se realizarán pruebas relacionadas con:

- Registro de equipos.
- Validación de datos.
- Consulta de equipos.
- Registro de estudiantes.
- Registro de préstamos.
- Validación de disponibilidad.
- Manejo de errores.
- Actualización de estados.
