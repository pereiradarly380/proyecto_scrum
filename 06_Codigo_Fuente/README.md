# Código Fuente

## Sistema de Préstamo de Equipos Tecnológicos

El proyecto está desarrollado utilizando Python y está orientado a ejecutarse mediante consola.

## Funcionalidades principales

El sistema contempla inicialmente:

- Registro de equipos tecnológicos.
- Consulta de equipos.
- Registro de estudiantes.
- Registro de préstamos.

## Calidad del código

Durante el desarrollo se busca mantener:

- Código organizado y legible.
- Uso adecuado de funciones.
- Nombres claros para variables y funciones.
- Validación de datos.
- Manejo básico de errores.
- Commits que permitan evidenciar el desarrollo incremental.
