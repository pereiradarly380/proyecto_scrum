# Registro de Impedimentos

## Sistema de Préstamo de Equipos Tecnológicos

Esta carpeta contiene el registro de los impedimentos identificados durante el desarrollo del Sprint.

Cada impedimento registra:

- Identificador
- Fecha
- Descripción
- Responsable
- Acción tomada
- Estado

## Impedimentos identificados

Durante el desarrollo se identificaron problemas relacionados con:

- Ingreso y manejo de cantidades de equipos.
- Control de errores del programa.
- Eliminación de equipos.
- Actualización de la cantidad disponible.
- Descuento de equipos prestados.
- Errores durante la ejecución de Python.

Los impedimentos serán actualizados conforme sean solucionados.
