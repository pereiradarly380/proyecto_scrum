# Tablero Scrum

## Sistema de Préstamo de Equipos Tecnológicos

Esta carpeta contiene las evidencias relacionadas con el tablero Scrum utilizado para gestionar el trabajo del Sprint.

El tablero permite visualizar el estado de las actividades y realizar seguimiento al avance del equipo.

## Flujo de trabajo

El proyecto utiliza los siguientes estados:

- Por hacer
- En curso
- En revisión / pruebas
- Listo

## Herramienta

La gestión del Sprint se realiza mediante Jira.
