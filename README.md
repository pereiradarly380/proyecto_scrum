# Sistema de Préstamo de Equipos Tecnológicos

## Descripción

MVP desarrollado en Python para gestionar el préstamo de equipos tecnológicos de una institución educativa.

## Funcionalidades del MVP

- Registrar equipos tecnológicos.
- Consultar equipos registrados.
- Registrar estudiantes.
- Registrar préstamos.

## Metodología

El proyecto se desarrolla utilizando el marco de trabajo Scrum.

## Historias de usuario seleccionadas

- HU01 - Registrar equipos tecnológicos.
- HU02 - Consultar equipos registrados.
- HU03 - Registrar estudiantes.
- HU04 - Registrar préstamo.
